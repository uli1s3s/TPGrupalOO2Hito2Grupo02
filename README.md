# CU RankingUnidadesVentas

Se implementa el ranking de unidades de venta por recaudación para el administrador.

- Funcionalidades:
Selección del festival a consultar.
Ranking de unidades ordenadas de mayor a menor recaudación.
Cálculo de ventas utilizando los precios históricos de los pedidos.
Validación de festivales inexistentes y manejo de rankings vacíos.
Incorporación del botón «Ver ranking de ventas» en la pantalla de Unidades.

- Implementación:
Nuevo DTO, servicio y controlador.
Nueva vista Thymeleaf integrada al diseño de Epicentro Gourmet.
Reutilización de los repositorios existentes, sin modificar su lógica.
